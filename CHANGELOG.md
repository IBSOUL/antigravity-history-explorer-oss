# Changelog - Antigravity History Explorer (OSS)

## [1.2.0] - 2026-05-08

### Adicionado

- **Onboarding Interativo**: Novo fluxo de boas-vindas para guiar o usuário na seleção de pastas locais.
- **Design System Premium**: Interface redesenhada com Glassmorphism, animações e Dark Mode profundo.
- **Reparo de Histórico**: Botão para re-indexar pastas e encontrar logs perdidos.
- **Tradução via IA**: Suporte a tradução de mensagens usando Google Gemini (configurável com chave própria).

### Melhorado

- **Performance**: Otimização na leitura de grandes volumes de arquivos via File System Access API.
- **Segurança**: Reforço na validação de caminhos no backend Rust.

## [1.0.0] - 2026-05-08

- Lançamento inicial da versão Open Source.
- Visualização de logs locais via navegador.
- Backend leve em Rust.

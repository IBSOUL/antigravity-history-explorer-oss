# UI/UX Guidelines - Antigravity

## Design System: Premium Dark

### Cores

- **Fundo Principal**: `#05070a` (Deep Space)
- **Superfícies**: `#0f172a` com opacidade (Glassmorphism)
- **Acento**: Gradients de `Indigo-500` a `Purple-500`
- **Texto**: Slate-200 (Primário), Slate-400 (Secundário)

### Componentes

- **Cards**: Border de 1px com transparência, backdrop-blur de 12px.
- **Botões**: Bordas arredondadas (Rounded-XL), efeitos de hover com glow sutil.
- **Sidebar**: Colapsável, ícones minimalistas.

### Animações

- **Transições**: 0.3s ease-out para hovers.
- **Entrada**: Fade-in-up para listas de conversas.
- **Loading**: Pulsação sutil nos esqueletos de carregamento.

### Princípios

1. **Foco no Conteúdo**: O log da conversa é o herói.
2. **Visual Moderno**: Evitar cinzas puros; usar tons azulados e profundos.
3. **Feedback Visual**: Todas as ações (Sync, Copy, Repair) devem ter estados visuais claros.
